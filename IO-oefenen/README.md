# IO-oefenen: *Onder de paramariboom* (Johan Fretz)

Oefenmateriaal voor de **Individual Oral (HL), Dutch B**: het hele boek in **100 fragmenten van ongeveer 2 pagina's**. Bij elk fragment staan een kant-en-klaar spiekbriefje van **10 bullet points** (samenvatting, verband met het hele werk en je mening volgens PEAL) en **vervolgvragen** voor deel 2.

> Paginanummers = pagina's van de PDF in deze repo. In de gedrukte uitgave kunnen ze iets verschillen.

## Zo oefen je met een klasgenoot

1. Laat je klasgenoot **twee** fragmenten kiezen (zoals op de echte IO). Kies er één.
2. **20 minuten** voorbereiden: lees het fragment in de PDF en maak je eigen 10 bullet points. Pas daarna kijk je hier ter controle.
3. **Deel 1 (3–4 min):** samenvatting → verband met het hele boek → mening (PEAL).
4. **Deel 2 (4–5 min):** je klasgenoot stelt de vervolgvragen uit dit bestand.
5. **Deel 3 (5–6 min):** praat over een **ander** IB-thema (zie het overzicht, §8).
6. Je klasgenoot geeft feedback met de rubric (A: taal 12, B1: fragment 6, B2: gesprek 6, C: interactie 6).

**Tip:** schrijf op de echte IO geen hele zinnen op je briefje, alleen trefwoorden. Leer 3–4 citaten uit je hoofd, zodat je ze bij elk fragment kunt gebruiken.
